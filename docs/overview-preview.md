# Мониторинг педагогов. Локальный стенд

На первом экране обе карточки читаются одинаково. Слева число педагогов и размер группы, справа доля и изменение в процентных пунктах. Объяснения под ⓘ описывают формулы, не повторяя текущие значения.

| Блок | Как считаем и показываем |
| --- | --- |
| Риск выгорания по модели | Последняя завершённая неделя к выбранной дате. Изменение относительно предыдущей недельной оценки, если есть оба результата |
| Истощение или бессилие по опросам | Последний опрос за 7, 28 или 90 дней до выбранной даты включительно, среди ответивших. Для изменения используется предыдущее непересекающееся окно той же длины |
| Стадии по опросам | По дате обзора доля от ответивших. За весь учебный год берём последние известные уровни из годового отчёта, доля от всех педагогов справочника. Охват годового отчёта может выходить за дату обзора |
| Ситуация по школам | Сумма по выбранным стадиям и цветные сегменты с их долями среди опрошенных. Нажатие на название оставляет одну стадию, плюс добавляет, крестик исключает. Охват считается от штата. По восемь школ на страницу |
| Прогноз по школам | Ожидаемая доля среди ответивших в следующие 28 дней. Берём последние три непересекающихся окна по 28 дней до даты обзора, по одному последнему ответу каждого педагога на окно. Доли взвешены числом ответов. При менее чем двух окнах с ответами оценка отсутствует |
| Педагоги | Список штата на выбранную дату и группа риска за завершённую неделю. Есть поиск, фильтр школы и сортировка. При возврате из досье сохраняются фильтры и страница |
| Досье | Оценка модели, последний ответ за выбранное окно, история опросов, ставка и нагрузка за восемь полных недель. Ставка берётся из кадровой записи, которую генератор заполняет для каждого педагога |
| Динамика | Истощение или бессилие и охват опросами на общей оси месяцев с двумя подписанными шкалами. Можно выбрать 6, 12 или 24 месяца. Наведение или фокус показывает обе базы и доли на дату. Динамика охвата сама по себе не показывает, кто перестал отвечать |

Для таблиц использованы разделение панели поиска и фильтров из [Carbon Design System](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines) и отдельная навигация страниц по [USWDS](https://designsystem.digital.gov/components/pagination/).

Для прогноза используется базовая оценка по прошлым наблюдениям. Она рассчитана отдельно от недельной оценки Random Forest. Качество прогноза на будущих окнах не проверялось. Подход к простым базовым прогнозам описан в [Forecasting: Principles and Practice](https://otexts.com/fpp3/toolbox.html).

Локальный режим рассчитывает две последние завершённые недели. Для более ранних дат недельная оценка отображается только при наличии расчёта. Индивидуальный список включается флагом локального обзора и доступен на loopback.

```sh
python3 generate.py --out /tmp/burnout-overview.db
python3 dashboard.py --database /tmp/burnout-overview.db --port 8082 --model-risk --overview-preview
```

На `/` и `/overview` открывается обзор, на `/people` список педагогов, на `/classic` прежний экран. Досье открывается по имени педагога в списке.
