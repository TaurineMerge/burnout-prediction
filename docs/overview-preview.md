# Выгорание педагогов. Локальное превью

Первый экран показывает величину группы риска и даёт путь от числа до списка педагогов или сравнения школ.

| Блок | Показатель | Источник |
| --- | --- | --- |
| Сигнал модели | Уровень 2+ за последнюю завершённую неделю, доля среди оценённых. Охват расчёта в ⓘ | `model_risk`, флаг `--model-risk` |
| Свежие опросы | Доля уровня 2+ среди ответивших, охват среди педагогов в штате | Последний валидный опрос за 28 дней, `teacher_staffing` на дату отчёта |
| Учебный год | Прежние показатели по трём стадиям, по последнему известному уровню каждого педагога во всей синтетической выгрузке | `summary.stages`, знаменатель от всего справочника педагогов. В выгрузку входят недели после даты отчёта |
| Ситуация по школам | Число ответивших, охват, количество и доля выбранного уровня. Заголовки сортируют столбцы | Свежие опросы и кадровый срез |
| Список педагогов | Фильтр по школе, свежая стадия, ставка и переход к существующему досье | Педагоги выше порога модели. Ставки из `teacher_staffing` |
| Динамика | Доля уровня 2+ или охват по месяцам, значения в отдельном окне по шесть строк | Кадровый реестр и свежие опросы на каждую дату. Последняя точка на дату отчёта |

Для структуры сравнения рабочих показателей использовали [NHS Workforce Data Hub](https://digital.nhs.uk/data-and-information/areas-of-interest/workforce/?area=data-visualisations) и [ONS Sickness Absence](https://www.ons.gov.uk/employmentandlabourmarket/peopleinwork/labourproductivity/articles/sicknessabsenceinthelabourmarket/2025). Сортировка реализована по принципу [таблиц NHS](https://service-manual.nhs.uk/design-system/components/table). Числа графика обновляются сразу. Пружины [Stat card](https://designbookmark.com/motion#db-stat-card) двигают линию и выделение выбранного показателя.

Модель оценивает риск уровня 2+. Прогноз ухода потребует отдельно определить целевое событие, срок и проверить модель. Кадровые данные и результаты расчёта на стенде синтетические. Список с именами служит для просмотра этого демо. Его маршрут доступен с флагом `--overview-preview`, который запускается только на loopback.

```sh
python3 generate.py --out /tmp/burnout-overview.db
python3 dashboard.py --database /tmp/burnout-overview.db --port 8082 --model-risk --overview-preview
```

На `/` и `/overview` открывается новый экран, на `/classic` доступна предыдущая версия.
