# Обзор педагогов. Локальное превью

Срез объединяет кадровый реестр и последние результаты опросов. Один педагог учитывается один раз. Граница актуальности 28 календарных дней включительно взята из предварительного предложения по метрикам. Расчёт на дату учитывает даты найма и ухода.

| Что можно посчитать | Что показываем | Источник |
| --- | --- | --- |
| Число педагогов и школ | Число педагогов в штате на дату среза, число школ | `teacher_staffing` |
| Свежесть и охват опросами | Свежие опросы из числа педагогов в штате. Отдельно число людей без результата | `teacher_staffing`, `survey_act` |
| Доля уровня 2+ и стадии 0–3 | Число и доля среди ответивших. Четыре части на одной полосе с подписями | `survey_act`, `burnout_type_dic` |
| Изменение доли уровня 2+ и охвата | Линия по месячным срезам, разница в процентных пунктах и таблица исходных значений. На последней точке используется дата отчёта | Те же источники для каждой даты среза |
| Ситуация по школам | Таблица с абсолютными числами, долей, охватом и сортировкой | Те же источники в группировке по школе |
| Средняя ставка и распределение | Среднее на педагога и горизонтальные полосы по доступным значениям | Генератор записывает `workload_fte` в `teacher_staffing`; прежние варианты и вероятности сохранены |
| Оценка риска моделью | Отдельный блок с размером группы риска, охватом и датами недели | `model_risk`, опционально через `--model-risk` |
| Часы календаря и активности, история анкет | Индивидуальная динамика в существующем досье | Недельная панель, расписание и опросы |
| Сообщения, длина сообщения, участники, больничные | Доступны для отдельного анализа нагрузки. Потребуются определения агрегатов и правила доступа | Недельная панель и расширенная панель |
| Ставка как признак модели | Понадобится сравнить модель со ставкой и без неё на временной валидации | `teacher_staffing`; модель из PR #5 пока использует исходные признаки |

Для графиков взяты форматы из [Financial Times Visual Vocabulary](https://github.com/Financial-Times/chart-doctor/blob/main/visual-vocabulary/README.md) и практики [Government Analysis Function](https://analysisfunction.civilservice.gov.uk/policy-store/data-visualisation-charts/). Сетка и порядок чтения опираются на [рекомендации GOV.UK для дашбордов](https://brand.design-system.service.gov.uk/data/dashboards/). Под графиком доступна HTML-таблица с исходными значениями по рекомендации [Analysis Function о доступных дашбордах](https://analysisfunction.civilservice.gov.uk/policy-store/data-visualisation-testing-dashboards-for-design-and-accessibility/).

Переключатель динамики и анимация используют пружины [Stat card](https://designbookmark.com/motion#db-stat-card). В исходнике `stat.js` заданы пары 200/17 для точек, 160/22 для числа и 380/30 для выделения. Самопереключение заменено явным выбором. График соединяет измеренные точки прямыми, а пропуски разрывают линию. Настройка снижения движения отключает интерполяцию.

Для проверки создайте отдельную синтетическую БД и откройте `/overview`. В корне `/` остаётся прежний экран. Кнопка «Досье педагога» ведёт к его существующей вкладке.

```sh
python3 generate.py --out /tmp/burnout-overview.db
python3 dashboard.py --database /tmp/burnout-overview.db --port 8082 --model-risk
```
